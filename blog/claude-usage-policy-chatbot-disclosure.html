Claudeの利用ポリシー改定（11月12日施行）— お客様向けAIチャットの「AIです」表示は開始時か画面上に置く

2026-10-16

自社サイトの問い合わせチャットに Claude を使っている。そこへ、提供元の利用ポリシー（使い方の決まり）が11月12日に新しくなると知った。

チャットの画面を直す必要があるのか、直すなら何をするのかが分からないまま日が過ぎると、施行日にその画面が決まりに合っているか説明できません。この記事で扱う問いは1つです。お客様向けのAIチャットに、提供元はどんな表示を求めているのか。先に答えを書くと、人ではなくAIとやり取りしていると利用者に伝える表示です。

この記事の結論

Anthropic の利用ポリシーは、お客様と直接やり取りするAIチャットに「人ではなくAIとやり取りしている」と伝える表示を求めています。この求めは2025年9月15日の版にもありました。11月12日に施行される2026年版では、表示の場所が「各チャットの開始時」から「各チャットの開始時、または画面上」に書き換わり、Anthropic・Claude・モデルの名前は示さなくてよいと明記されました。

2026年10月16日に、私たちは発表ページと2つの版の本文を読み比べて確かめました。

お客様向けのAIチャットに、提供元はどんな表示を求めているのか

利用ポリシーは、Anthropic が Claude の利用者に求める決まりです。Claude.ai や Claude Code を使う個人のほか、API で自社の製品に組み込む会社、クラウドや販売会社を通じて使う会社、Claude を組み込んだ製品の利用者も対象と書かれています。

決まりは3つに分かれています。誰にでも当てはまる禁止事項、健康やお金など影響の大きい使い方への要件、そしてお客様向けチャットなど一部の使い方への追加の決まりです。AIである旨の表示は、3つ目の追加の決まりにあります。

お客様向けチャットについては、外部の利用者と直接やり取りするチャットボットやAIエージェントが対象とされています。書きぶりの細部は、次の章で2025年版と並べて見ます。

利用ポリシーは、直接契約している会社も、サービス会社を通して使う会社の利用者も対象としています。自社で画面を直せるのか、契約元やサービス会社に頼むのかは、契約先に確認してください。

2025年版と2026年版で、表示の求めはどこが変わったのか

2025年9月15日の版と、2026年11月12日施行の版で、お客様向けチャットの表示の部分を並べます（2026年10月16日に Anthropic の公開ページで確認。原文は英語で、要約は私たちによるものです）。

項目2025年9月15日の版2026年11月12日施行の版
対象お客様向けのチャットボット（外部向けの対話型AIエージェントを含む）外部の利用者と直接やり取りする、お客様向けのチャットボットとAIエージェント
表示の場所（最低限）各チャットの開始時各チャットの開始時、または製品の画面上
提供元やモデルの名前記載を確認できず示さなくてよい

表示を求める点は同じです。2026年版は、表示の場所を「開始時」に限らず「画面上」でもよいことにし、名前を示さなくてよいことを書き足した形です。Anthropic の発表も、今回の更新の多くは既存の決まりを明確にするものだと説明しています。「2026年版で新しく表示が必要になった」と読むと、本文と合いません。

読者の疑問

「うちのチャットは、最初から『AIアシスタント』という名前を付けている。それで足りるのでは」

「AIアシスタント」という名前だけで足りるかは、利用ポリシーの本文から言い切れません。画面に「AIが回答します」と分かる一文を出しておくと、利用者にAIだと伝わっているかを、自社で確かめやすくなります。ほかの決まりや日本の法令への適合は、この一文では判断できません。

「AIです」の表示は、開始時と画面上のどちらに置くか

2026年版が最低限として挙げているのは、開始時か画面上のどちらかです。どちらに置くかは、会社が自社のチャットで決めます。お客様がチャットを開いた場面で、それぞれの置き方がどう見えるかを、3つに整理します。

01 開始時に出す

チャットを開いた最初に、AIが回答する旨の一文を出します。履歴を開き直したときに消える作りだと、その人には見えません。

02 画面上に出し続ける

入力欄の上や、チャット枠の見出しなど、会話の間ずっと見える場所に出します。スマホの小さな画面で隠れていないかを見ます。

03 両方に出す

開始時の一文と、画面上の常時表示を重ねます。文言を変えるときの直し先は2か所になります。

文言は短くします。たとえば「このチャットはAIが回答します。人に相談したい方は、こちらからご連絡ください」です。人に戻す入口の作り方は、「小さな会社のAIチャットボット運用— 最初に決めたい『人に戻す』5つのルール」に書いています。

迷うときは、お客様が会話の間ずっと目にできる置き方を出発点にします。そのうえで、スマホの画面で隠れていないかを確かめます。

健康・お金・仕事で個人への助言や判断を出すときは、表示とは別に人の確認が要る

表示を決めたあとに確かめたいのは、チャットの回答の中身です。採用・労務・お金・法律・医療で個人への助言や判断を出す作りなら、表示とは別に、人の確認が要ります。AIの回答がこの分野に当たらなければ、この章は読み飛ばして構いません。

利用ポリシーの本文によると、健康、法的な権利、お金、生計（仕事）、生活に欠かせないサービスに影響する使い方で、個人への助言や判断を出すときは、人の確認と、本人へのAI利用の告知が要ります。法律の内容や病気の仕組みを一般的に説明するだけの回答や、社内の下書き・調べ物は、対象から外されています。確認する人は、その分野の訓練か経験があり、法令が資格を求める分野ではその資格を持つ人です。内容を変える権限をもって、届ける前に見ます。

Anthropic の発表は、この要件は変わっていないと説明しています。2026年版が書き直したのは、どの使い方が該当するかの一覧です。小さな会社で関わりやすい分野を、2026年版の本文から挙げます。

  • 採用：候補者の選別、順位付け、不採用の決定
  • 労務：シフト・労働時間・給与の設定や変更、従業員の評価や懲戒
  • お金：個人の税金の助言（何を申告し、何を控除するか）、署名や提出をする申告書の作成
  • 法律：個人の権利や義務についての助言、署名や提出をする書類の作成
  • 医療：症状や検査結果の解釈、治療や薬についての提案

お客様向けチャットがこうした回答を出す作りになっていると、AIの表示に加えて、出す前に人が見る仕組みと、AIが使われたと本人に伝える文が別に要ります。日本の法令でどう扱われるかは、ここでは扱いません。

自社のチャットを開いて確かめる手順

施行日の前に、自社のチャットを実際に利用者と同じ画面で開きます。確かめる点は5つです。

  • スマホとパソコンの両方で、チャットを開いた最初の画面を見る
  • 「AIが回答します」と分かる一文が、開始時か画面上に出ているかを確かめる
  • 出ていないなら、一文を足す場所を決める（開始時、画面上、両方）
  • 採用・労務・お金・法律・医療に関わる質問を1つずつ送り、AIが個別の助言や判断を答えていないかを見る
  • 答えているなら、回答を止めて人に回す入口と、AIが使われたと本人に伝える文があるかを確かめる

チャットを自社で作っていない場合、画面の直し先は契約元かサービス会社です。表示の文言と置き場所を決めて、直してもらいます。確かめた日付と画面を1枚、社内に残しておくと、あとから「いつ、何を直したか」を説明できます。表示の求めは2025年版からあるため、すでに表示を出している会社も、同じ手順で置き場所と文言を見直します。
