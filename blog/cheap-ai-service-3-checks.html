ChatGPT・Claudeを安く使えるサービスの見分け方 — 申し込む前に確かめる3つ

2026-09-25

「ChatGPT も Claude も、1つの契約で公式より安く使えます」。AIの費用を抑えたくて調べていると、こうした案内のサイトに行き当たります。

その安さの理由が、盗んだアカウントの転売だった例があります。案内に従って入れたソフトが、PCからログイン情報を抜き続けていました。会社として申し込む前に、どこを見れば見分けられるか。それがこの記事の問いです。

この記事の結論

見分ける目安は3つあり、どれもサービスのサイトを数ページ開けば確かめられます。欠けている目安があれば申し込む前に問い合わせ、答えが無ければ止めます。3つは、Anthropic が2026年9月10日に公表した悪用対策の報告に載った手口をもとに、この記事で組み立てた目安です。

公式より安く使えるのはなぜか — 報告に載った格安サービスの中身

Anthropic は2026年9月10日、自社のAIが悪用された事例をまとめた報告を公開しました。対象は、2025年12月から2026年8月までに止めた活動です。その中に、AIを安く使いたい人を狙う手口が1節あります。

手口の1つは、複数のAIをまとめて中継するサービスを名乗るサイトでした。最先端のAIを割引価格で使えると案内します。被害の入口はいくつかあり、中でも長く続いたのが専用ソフトを入れさせる方法でした。ソフトは Claude Code など人気の道具に見せかけてありました。実際には、PCに保存されたログイン情報と、ログインしたままの状態を丸ごと送る仕組みでした。

もう1つは、安い Claude を売っていた業者の例です。報告はこれを「安くもなく、Claude でもなかった」と書いています。利用者の依頼は、黙って別のAIに回されていました。その裏でソフトが入り、利用者の Anthropic のアカウントが盗まれ、別の転売業者へ売られていました。

この記事で扱うのは、こうした外部の格安サービスです。アプリ経由の課金や割引のように、公式の契約そのものを安くする方法の話ではありません。

盗まれたアカウントは、売り物・攻撃の費用・隠れ蓑になる

なぜAIのアカウントが狙われるのか。報告は、AIのログイン情報を手に入れた側が、3つを一度に得ると書いています。

1つ目は売り物で、盗んだアカウントには転売する市場ができています。2つ目は攻撃の費用で、攻撃に使うAIの利用料を、アカウントの持ち主の負担にできます。3つ目は隠れ蓑です。記録の上では、その利用は持ち主のものとして残ります。会社のアカウントなら、会社の名前で残ります。

この節の締めくくりは、はっきりしています。AIは正規の経路で買うこと。知らない中継役に通信とログイン情報を預ける割引は、大きな危険を持ち込むこと。では、知らない中継役をどう見分けるか。私たちは、報告の手口と締めくくりの警告を裏返して、次の3つの目安にしました。

01 運営会社

報告は、知らない中継役に通信とログイン情報を預ける割引を危険だとした

02 求められるもの

報告のソフトは、人気の道具に見せかけてあった

03 お金とデータの行き先

報告の業者は、Claude と称して別のAIに回していた

確かめる1 運営会社が名乗っているか

報告が危険だとしたのは、通信とログイン情報を、知らない中継役に預ける割引でした。知らない相手かどうかを見る最初の手がかりは、運営会社を名乗っているかです。社名、代表者、問い合わせ先の3つがそろっているかを見ます。トップページに無ければ、プライバシーポリシーや利用規約のページも開きます。

会社として申し込めば、何かあったときに連絡を取るのも会社です。その相手と連絡がつくかどうかを、申し込む前に確かめておきます。社名が無く、連絡の手段がSNSのアカウントだけなら、ここで止めます。

名乗っていることは、安全の証明ではありません。それでも、名乗っていない相手には、あとから何も確かめられません。3つのうちで、いちばん早く見分けられる目安です。

確かめる2 自分のAIアカウントやソフトのインストールを求めないか

2つ目は、申し込みや利用の手順の中で、何を求められるかです。報告の手口で被害が長く続いたのは、専用ソフトのインストールでした。ソフトを入れたPCからは、AIに限らず、保存されたログイン情報がまとめて送られていました。

見るのは2つです。1つは、手持ちの ChatGPT や Claude のログイン情報や、開発者向けの鍵（APIキー）を入力させる手順が無いか。もう1つは、ブラウザで使えるはずのものに、専用ソフトや拡張機能の追加を求めないかです。どちらかがあれば、業務PCで進める前に、社内でPCを管理している人に見せます。

読者の疑問

「公式のアプリと見た目が同じなら、見分けようがないのでは」

見た目では見分けません。報告のソフトも、人気の道具に見せかけてありました。判断の材料は、どこから入手したかです。提供元の公式サイトからたどれない入手先のソフトは、業務PCに入れない。これを社内の約束にしておきます。

確かめる3 お金とデータの行き先が書いてあるか

3つ目は、払ったお金と入力したデータがどこへ行くかです。支払いは、誰がどう処理するのか。入力した文章はどこに保管され、AIの学習に使われるのか。依頼を、どの会社のAIにつないでいるのか。

中継型のサービスで依頼がどのAIに届いているかは、使う側は運営の説明で知るしかありません。報告の業者の利用者は、Claude を買ったつもりのまま、依頼を黙って別のAIに回されていました。つなぎ先が書かれていないAIには、問い合わせて答えを得るまで、社内の資料を入れないでおきます。

書いてあれば、あとで食い違ったときに問い合わせる根拠になります。書いていない相手には、その糸口もありません。

3つを実際のサービスに当てると — PromnyAI の公開情報で試す

例として、私たちの PromnyAI に3つを当ててみます。複数のAIを1か所で使うサービスで、形の上では報告の中継型と同じ側にいます。2026年9月25日時点の公式サイトで確かめた内容です。

  • 運営会社：株式会社i-Style（石川県金沢市）。代表者名と問い合わせフォームも、プライバシーポリシーのページに載っています。
  • 求められるもの：PC・タブレット・スマートフォンのブラウザで使います。各AIを個別に契約せず、1つのアカウントで使う形です（トップページ）。
  • お金とデータの行き先：決済は Stripe で、カード情報は PromnyAI のサーバーを通りません。保管先は Google Cloud 東京リージョンで、入力したデータはAIの学習に使いません。AIの提供元として、セキュリティのページに OpenAI・Anthropic・Google の3社が載っています。

ただ、トップページに並ぶAIのうち、Grok と Perplexity の提供元の会社名は、セキュリティのページにありません。業界特化のAI8種がどの会社のAIで動くかも、書かれていません（いずれも2026年9月25日時点）。3つ目の目安に照らすと、これらは申し込む前に問い合わせて確かめる項目として残ります。

読者の疑問

「3つがそろっていれば、安全なサービスと言えますか」

言えません。3つは、知らない中継役を避けるための入口の目安です。PromnyAI のセキュリティのページにも、注意書きがあります。SOC 2 などの認証は基盤の各社が取得・準拠しているもので、PromnyAI が直接取ったものではない、という内容です。認証を誰が持っているのかまで読んでおくと、ほかのサービスと並べる場面でも同じ物差しが使えます。

入れてしまったら、パスワードより先にやること

ここまでは、申し込む前の話です。すでにソフトを入れてしまったときは、順番が変わります。報告では、乗っ取られたと分かってアカウントがリセットされても、ソフトはそのPCで新しく始まったログインを見つけて送り続けていました。ソフトが残ったPCでログインし直せば、そのログインも同じように送られる形です。

やることは、順に3つです。1つ目に、そのPCでのログインを止めます。社内でPCを管理している人に伝え、そのPCの扱いを任せます。2つ目に、別の端末からパスワードを変え、ログイン中の端末をすべてログアウトさせます。3つ目に、開発者向けの鍵（APIキー）を使っていたら作り直します。

報告で抜かれていたのは、パスワードだけでなく、ログインしたままの状態と鍵でした。判断に迷うときは、情報処理推進機構（IPA）の企業組織向けサイバーセキュリティ相談窓口に、初動の対応を相談できます。

入れる前に止めるほうが、ずっと手間は少なく済みます。社内でAIを使うときの約束に、次の確認を足しておきます。約束そのものの作り方は、別の記事（小さな会社の生成AI利用ルール）に書いています。

  • 運営会社の社名・代表者・問い合わせ先が、サイトに載っている
  • 手持ちのAIのログイン情報や、開発者向けの鍵の入力を求めない
  • ブラウザで使えるはずのものに、専用ソフトや拡張機能の追加を求めない
  • 支払いの仕組み、データの保管先、つないでいるAIの会社が書いてある

AIの費用を抑えたいという考えは、まっとうです。ただ、安さの理由が書かれていない相手に、会社のログイン情報を預ける理由にはなりません。「公式より安い」のページを見つけたら、上司に許可を取りに行く前が確かめどきです。運営会社、求められるもの、お金とデータの行き先の3つを、先に開いておきます。
