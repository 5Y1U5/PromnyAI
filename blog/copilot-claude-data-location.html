Microsoft CopilotのClaude設定とデータの保存先 — 処理の場所と委託先の確かめ方

2026-11-06

「Copilot に入れたデータは、日本にあるんだよね」。社長にこう聞かれて、そのまま「はい」と答えそうになったときは、一度止まってください。Microsoft の公式文書は、データの保存と処理の場所を別々に説明しています。

この記事の結論

「保管は日本」だけでは、社内の質問に答えきれません。確かめるのは、保存先・処理の場所・関わる会社（委託先）の3つです。

Copilot なら、Microsoft 365 管理センターの「Microsoft のサブプロセッサとして動作する AI プロバイダー」で、Claude と OpenAI のモデルを誰が使えるかを見ます。保存先は同じ管理センターの「データの場所」のカード、処理の場所は Microsoft Learn の説明で確かめます。

11月5日の発表のあと、日本のCopilotのClaudeはどう扱われるのか

今回の発表で、日本の会社の扱いが変わるとは書かれていません。Microsoft は2026年11月5日、Copilot の Claude を年末までに EU データ境界の中で処理すると発表しました。EU データ境界は、データの保存と処理を EU と EFTA（欧州自由貿易連合）の中で行う Microsoft の約束です。発表の対象は、EU と EFTA の組織です。

日本の担当者が読むべきは、発表の前提です。今の Claude は、EU データ境界の約束の外にあります。Claude の提供元である Anthropic は、Microsoft の委託先（サブプロセッサー）という扱いです。

日本の中で処理する約束はどうなっているのか。Microsoft の国内処理の発表に2026年4月3日に足された追記では、日本国内で処理する対応は2028年の見込みです。当初は2025年末までの予定でした。さらに Microsoft Learn（2026年11月4日更新）は、国内処理の約束がある場合も Claude は対象外と書いています。

設定の初期値も地域で違います。同じ Learn のページによると、商用クラウドのほとんどの顧客で Claude は既定で有効です。除外として名前があるのは EU、EFTA、英国で、日本の名前はありません。導入の手続きをした覚えがなくても、管理者が制限していなければ、社員が Claude を選べる状態かもしれません。

OpenAI のモデルにも、Claude と同じく Microsoft の委託先として動くものがあります。OpenAI が自ら動かすモデルは、2026年7月24日から、管理者が「ユーザーなし」にしていなければ、対象の商用顧客の全員で有効です。国内処理の約束の対象外という点も Claude と同じです。Microsoft が自社で動かす OpenAI のモデルは別の扱いで、委託先の設定を切っても使えます。

読者の疑問

「Copilot は全部 Microsoft の中で動いているのでは」

Microsoft が自ら運用するモデルについては、データが Microsoft の外に出ないと公式文書で説明されています。Claude と、OpenAI が自ら動かすモデルは別です。提供元の会社が委託先として処理に関わり、Microsoft が契約で監督すると説明されています。

「保管は日本」で答えられない2つ — 処理の場所と関わる会社

ここまで読むと、社長の質問に「はい」の一言では返せないと分かります。データの行き先を聞かれたときは、問いを3つに分けます。Copilot の記載を並べると、次のようになります。

確かめること何を聞いているかCopilot の公式の記載（2026年11月6日確認）
保存先入れた文章とやり取りが、どこに残るか組織ごとの場所は、管理センターの「データの場所」のカードで見る。Microsoft 365 Copilot は載るが、Copilot Chat は載らない
処理の場所AIが答えを作るとき、どこで動くかEU の外の顧客の問い合わせは、米国、EU、その他の地域で処理される場合がある。混み合うと他の地域も使う
関わる会社Microsoft のほかに誰が扱うかLearn に委託先として説明があるAIモデルの提供元は Anthropic と OpenAI。誰が使えるかは管理者が決める。委託先の全体は Service Trust Portal の一覧で見る

保存先だけを見て「日本です」と答えると、下の2行が抜けます。取引先との契約に「国外に出さない」とある会社は、ここで止まってください。その約束が処理の場所まで含むのかは、契約書を読まないと分かりません。当てはまるかの判断は、契約の担当者や顧問の専門家に任せます。

保存先の欄にも、未確認が残ります。既定の設定で Claude を使ったときに限った保存先の説明は、確かめたページには見当たりませんでした。メモに「Claude 利用時は未確認」と書き、後の問い合わせ文で Microsoft の窓口に聞きます。

学習に使うかどうかは、この3つとは別の問いです。Microsoft は、プロンプトと回答を基盤モデルの学習に使わないと書いています。それでも、処理の場所の答えにはなりません。次は3つを順に確かめます。

Copilotを契約している会社が開く画面はどれか

ここからは、法人で Copilot を使っている会社の手順です。個人向けの Copilot は別の話になります。委託先の設定を操作できるのは、AI 管理者かグローバル管理者です。

3つを確かめる7つの手順

  • 1. 保存先: Microsoft 365 管理センターの「設定」から「組織の設定」「組織プロファイル」「データの場所」と進み、カードを見る
  • 2. 処理の場所: Microsoft Learn の「Microsoft Copilot のデータ、プライバシー、セキュリティ」を読み、書かれている地域と URL を控える
  • 3. 関わる会社: 管理センターの「Copilot」から「設定」を開き、「すべて表示」または「ユーザー アクセス」に進む
  • 4. 「Microsoft のサブプロセッサとして動作する AI プロバイダー」を選ぶ（英語の画面は AI providers operating as Microsoft subprocessors）
  • 5. Anthropic と OpenAI について、全員・一部の人・誰も使えない、のどれかを見る
  • 6. 「データ保持付き Anthropic モデル」の設定が、オフのままかを見る
  • 7. 見た日と画面の状態を、メモに書く

画面の名前は Microsoft Learn の日本語版（機械翻訳）から取ったもので、私たちが実際の管理画面で確かめたものではありません。言葉が違う場合は、英語の名前で探してください。

手順1のカードには「現在の地理」と「コミットされた地理」の列があります。前者は今データがある場所、後者は Microsoft が保存を約束する場所です。約束が無ければ「コミットメントなし」と出ます。Copilot Chat だけの会社は、カードに載らないので Learn と窓口で確かめます。

手順6の「データ保持付き Anthropic モデル」は既定でオフです。オンにすると、Anthropic がほとんどの入力と出力を最長30日保存します。この保存は Microsoft の契約の対象外です。違反の可能性があると判定された内容は、最長2年保持される場合もあります。オンにするなら、Anthropic の条件も読みます。

見た後は、切る以外に、使う人をグループで絞る方法もあります。Microsoft は、Anthropic を切ると使えなくなる機能があると書いています。切っても絞っても、処理が国内に収まるとは公式文書に書かれていません。

取引先との契約に国外処理の制限がありそうなら、確認が済むまで、その取引先の資料を Copilot に入れないと決めます。制限が無いと確かめて全員のままにするなら、Anthropic と OpenAI が関わると承知したうえで、理由と一緒にメモに残します。個人情報を入力する場合の扱いは別に確かめ、顧問の専門家に任せます。

公式ページに処理の場所が書かれていないAIサービスには、何を聞くか

Copilot で未確認が残った欄も、社内で使う ChatGPT や Gemini も、問いは同じです。先に公式のセキュリティのページで「保管」「リージョン」を探し、次に委託先の一覧を探します。

書かれていないことを「無い」とも「国内だけ」とも読まないでください。読めるのは「このページからは分からない」までです。メモ（6行の中身は最後の章で示します）に「未確認」と書き、提供元に聞きます。次の文面は、そのまま問い合わせフォームに貼れます。

問い合わせ文の例

御社のサービスを社内で使うにあたり、3点を教えてください。

1 入力した文章と回答を保存する国・地域
2 AIが回答を作るときに処理を行う国・地域
3 処理に関わる外部の会社の一覧

公開のページがあれば、URL をいただければ十分です。

返事が来たら、日付と一緒にメモへ写します。返事が来ない、または答えられないと言われたときも、そのまま「未確認」として残します。空欄にしないことで、次に見る人が調べ直す手間を減らせます。同じ問いを、私たちのページにも向けます。

PromnyAIの処理の国は、公式ページで分かるか

PromnyAI の公式ページで言えるのは「Google Cloud 上の保管は東京」までです。「処理も国内」とは言えません。私たちも、自社のセキュリティのページを同じ3項目で読み直しました（2026年11月6日）。私たちのページにも、書いてあることと書いていないことがあります。

確かめること書いてあること書いていないこと
保存先Google Cloud 東京リージョン（asia-northeast1）に保管Dify（AIアプリケーション基盤）の側で記録が残る場合の場所
処理の場所AIへの送信は応答を作る目的に限るAIの提供元と Dify が処理する国・地域
関わる会社Google Cloud、Dify、Stripe、AIの提供元として OpenAI・Anthropic・GoogleGrok と Perplexity の提供元（どちらも使えるAIの一覧にあるが、このページに名前が無い）

学習については、公式ページに「お客様のデータはAIモデルの学習用に利用されることはありません」とあります。提供元ごとの記載があるのは OpenAI・Anthropic・Google です。社内の決まりで処理の場所や委託先まで確かめる必要があれば、上の問い合わせ文をお問い合わせフォームに送ってください。

社内で聞かれたときに渡す1枚には何を書くか

ここまでメモに書いてきたことは、聞かれた人の頭の中に置かず、1枚にまとめます。次に社長や取引先に聞かれたときに、調べ直さずに渡せるからです。

1枚に書く6行

  • サービス名と契約の種類
  • 保存先（出典の URL）
  • 処理の場所（出典の URL）
  • 関わる会社（出典の URL）、社内で使える人、そう決めた理由
  • 確認した日と、確認した人
  • 未確認の項目と、聞いた先

確認した日を外さないでください。Microsoft Learn の Claude のページは2026年11月4日に更新され、EU の扱いは年末までに変わる予定です。日本の国内処理の見込みも、2026年4月の追記で2028年に変わりました。自社のメモも、見直す月を決めておきます。

「未確認」が残ったサービスに何を入れるかは、次の判断です。資料の仕分けは、別の記事「AIに社内資料を読ませる前に分けているか」にまとめています。処理の場所が分からないサービスには、取引先との約束がある資料を入れない、という分け方があります。

冒頭の質問に戻ります。「日本にあるんだよね」には、保存先、処理の場所、関わる会社の順に答え、最後に Claude を社内で使える人を添えます。分からない欄は「未確認で、提供元に聞いています」と言えば足ります。どこまで分かっていて、どこを聞いているかが、社長にも伝わります。
