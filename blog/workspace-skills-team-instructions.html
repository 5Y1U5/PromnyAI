AIへの指示をチームで配る前に確かめること — Google Workspace の skills と、自社側に残す指示文

2026-11-13

使いたい指示文が、担当者のチャット履歴にしかない。そんな状態では、担当者が不在のときに最新版を確かめにくくなります。チームで使う指示文は、どこに置き、どう配ればよいのでしょうか。

この記事の結論

2026年11月、Google Workspace の skills の展開が始まりました。利用条件と共有の仕組みを確認してから、社内で使う範囲を決めましょう。

以下は、公式仕様を踏まえた運用の提案です。配る前に言語・対応アプリ・コピーの扱い・参照権限・同期を確認し、社内で原本の置き場所を決めます。

指示文と一緒に何を共有するか

指示文だけでなく、入力しない情報と人が確認する範囲も共有する案です。履歴から抜き出す際は、顧客名や社内情報が残っていないか確かめてください。

2026年11月に始まった Workspace の skills とは何か

2026年11月10日の Google Workspace Updates によると、skills は再利用できるカスタム指示です。チームのルール、テンプレート、参考ファイルを Gemini が使うように指示します。

Workspace Studio と Google Docs で作成・テスト・共有できます。Studio では Markdown 形式の SKILL.md を直接編集できます。

対応するのは Gmail / Docs / Slides / Drive / Chat です。有効にした skill は、関連すると判断された場面で使われ、@mention で指定することもできます。

Rapid Release は2026年11月9日から最大15日かけて展開され、Scheduled Release は11月30日からです。対象は Business Starter / Standard / Plus などで、18歳以上の利用者向けです。

対象エディションでは既定でオンですが、管理者が無効化できます。対象であっても、展開状況と自社の管理設定を確認してから案内しましょう。

共有前に確かめる言語・アプリ・権限

以下は2026年11月12日に確認済みの公式情報です。右の列は、それに対応する社内運用の提案です。

確かめること公式の記載（2026年11月12日確認）配る側がすること
言語現在、英語のプロンプトと指示のみ日本語の指示文をそのまま載せる前提で計画を立てない
使えるアプリGoogle Sheets と Google Meet ではまだ使えないSheets・Meet 内で使う前提にしない
共有の形Studio からの共有は相手の独立したコピーになり、あとから元を直しても既に保存したコピーは上書きされない直したときに配り直す段取りを決める
参照ファイルskill が Drive ファイルを参照するなら、そのファイルの共有も必要指示と一緒に、参照先の共有範囲も確認する
Gemini アプリとの同期Workspace で作った skills は Gemini アプリの skills / Gems と自動同期しない両方で使う場合は、それぞれの設定と更新方法を確認する

共有先は独立したコピーなので、原本を直すだけでは更新が届きません。変更点と原本の場所を伝え、受け取った側で差し替えを確認する運用を提案します。

Gems の移行は Gemini アプリ側の話です。Workspace の skills と自動同期する説明ではないため、社内案内でも区別してください。

原本に何を残すか

社内で管理する原本には、指示と利用条件を一緒に残す案です。サービスを変える場合にも、必要な内容を取り出して確認できます。

原本に残す内容の例

  • 指示文そのもの。そのまま貼り付けられるテキストの形で残す
  • その指示文で何の仕事をするのか。対象の仕事と、使う人
  • 使ってはいけない情報。入力しない項目と、最後に人が見る範囲

置き場所は、担当者以外も開ける社内文書などを選びます。考え方は引っ越せる指示書の記事でも紹介しています。

PromnyAI の公式トップには、指示テンプレートを保存してチームで共有するプロンプトライブラリが紹介されています。共通の指示を置く候補として検討できます。

Workspace skills 連携や SKILL.md 取り込みは公式トップに記載されていません。これらを使える前提にはせず、必要なら利用可否を問い合わせてください。

原本は誰が持ち、コピーはどう直すか

原本の管理担当と、変更を知らせる方法も決めておきます。以下は人数や組織の形を固定しない、運用のたたき台です。

社内で決める順番

  • 原本の管理担当と置き場所を決める
  • 対象の仕事と配る範囲を決める
  • 配る前に利用条件と共有設定を確認する
  • 更新時の連絡方法と差し替えの確認方法を決める

更新時は、指示文の変更箇所と適用する仕事を伝えます。受け取った側が手元で加えた内容も確認してから差し替えると、残す変更を判断できます。

PromnyAI では、管理者によるアカウント発行・削除が公式に案内されています。利用者の管理と指示文の管理は別の仕事として、担当間の連絡方法も決めましょう。

指示の参照元を整理する際は、自社情報の整理記事も参考にできます。参照先を変えたときは、利用者が開けるかも確認してください。

共有前後の確認事項

  • ・指示文と社内ルールを、担当者以外も確認できる場所に置く
  • ・Workspace skills は対象・展開状況・管理設定を確認する
  • ・利用条件は、英語のみ／Sheets と Meet は未対応／共有はコピー／Drive の参照権限／Gemini アプリと非同期
  • ・原本には指示文・対象の仕事・入れない情報を残す案
  • ・原本を持つ人と、直したときの伝え方を先に決める

原本の置き場所と更新の伝え方を、指示文と一緒に共有しましょう。
